# Corazón Jefe

The official coming-soon landing page for **Corazón Jefe**, a luxury fragrance brand built around distinctive scent profiles, strength, longevity, and presence.

> Born from passion.  
> Destined to lead.  
> Aura that owns the room.

## About

Corazón Jefe is the culmination of over a decade of blending and refinement driven by an obsession with engineering distinctive, powerful scents.

This site serves as the brand's initial digital presence while the full storefront and fragrance collection are being developed.

## Features

- Responsive landing page
- Animated scroll-reveal typography
- Directional text animations
- Interactive highlighted words
- Social media links
- Email signup / early-access collection
- Mobile and desktop layouts
- Branded gradient and visual effects

## Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **Brevo** for email collection
